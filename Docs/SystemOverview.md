# System Overview

## 概要
SDF Make Supporter for lilToonは、グラデーション画像からSigned Distance Field (SDF) テクスチャを生成するWindowsデスクトップアプリケーションです。VRChatのアバター制作ワークフロー、特にlilToonシェーダーを使用する際のテクスチャ作成を支援します。

## アーキテクチャ

システムは大きく分けて以下の3つのコンポーネントで構成されています。

### 1. GUIレイヤー (`main.py`)
- **フレームワーク**: CustomTkinter
- **役割**:
  - ユーザーインターフェースの提供（画像選択、プレビュー、設定）
  - イベントハンドリング
  - アプリケーションライフサイクルの管理
  - ファイル監視の制御
  - Windowsフォントの適切な選択と設定

### 2. ロジックレイヤー (`sdf_processor.py`)
- **核となるクラス**: `SDFProcessor`
- **役割**:
  - 画像の読み込みと前処理 (NumPy, PIL)
  - SDF生成アルゴリズムの実装
    - Rチャンネル: 右光源用（反転マスク）
    - Gチャンネル: 左光源用（通常マスク）
    - Alphaチャンネル: 元画像のAlpha保持
  - 結果の保存処理

### 3. ユーティリティ/インフラ
- **ファイル監視**: `watchdog` ライブラリを使用し、バックグラウンドでの変更検知を行う。
- **ビルドシステム**: `PyInstaller` を使用し、単一のEXEファイルにパッケージング。

## データフロー
1. **入力**: グラデーション画像 (PNG, JPG等)
2. **処理**: 
   - 画像をグレースケール変換しマスクを作成
   - マスクを反転してRチャンネルへ
   - 元マスクをGチャンネルへ
3. **出力**: SDFテクスチャ (PNG)

## ディレクトリ構成（現状）
- `main.py`: エントリーポイントおよびGUI実装
- `sdf_processor.py`: 画像処理ロジック
- `Docs/`: ドキュメント類
- `build_exe.ps1` / `.spec`: ビルド設定
- `sample_images/`: テスト用画像
